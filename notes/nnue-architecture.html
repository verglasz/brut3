NNUE 64·512·128·4

The table-driven network behind models/nnue-64-512-128-4_mediumnet-full, the model the Haskell engine is exported from. It reads a position from the side to move's view and returns win/draw/loss logits and one logit per move.

embedding 64 accumulator 512 hidden 128 layers 4 (1 dense + 3 residual) parameters 1,588,484 multiply-adds after folding 126,976

One evaluation, as trained

  1. Board tokens, 64 each: t_k = E[c_k] + Σ_i E[cell_k,i] for the nine boards, and t_f the same for the forced board (or the “none” token).
  2. Accumulator, 512: acc = ReLU(Σ_k W_k·t_k + b_mix + F·t_f + Σ_j R[f_j]), with W_k the nine 512 × 64 blocks of mix, F = forced_mix (no bias) and R[f_j] the eleven feature rows.
  3. First hidden layer, 128: h = ReLU(W₁·acc + b₁), W₁ 128 × 512.
  4. Three residual layers: h ← ReLU(h + W_l·h + b_l), each W_l 128 × 128. With the reglu D option instead h ← h + W_down·(ReLU(W_gate·h + b) ⊙ (W_up·h + b)) + b, gate and up D wide.
  5. Value, 3 logits: wdl = V·h + b_V + S·acc, S 3 × 512 without bias.
  6. Policy, 81 logits: p[b·9 + s] = (P·h + b_P)[b·9 + s] + L[c_b][s] + T[c_s], playing square s of board b also sending the opponent to board s.

Of the biases, only mix's is redundant: every position also sums exactly one forced-token row and one forced-board feature row, so a constant shift could live in either.

brut3 · nn::nnue_v2 · reworked trunk and heads

nnue-v2 64·512·128·4 · reglu 128

The same tables and accumulator as the NNUE, then an unrectified projection that gates its first layer, ReGLU blocks, and heads in which the later layers decide how much the shortcut terms count. Drawn at hidden width 128 with ReGLU blocks of width 128; the model trained as nnue-v2-64-512-96-4-reglu-96 has the same structure at width 96.

Status: the trunk (projection, gated layer, ReGLU blocks, optional ReZero) is implemented as nnue-v2 E A H L reglu D [rezero]. The gated heads, the convex value mix and the gated policy tables, are the planned mix option and not built yet; the trained model has the NNUE's heads.

embedding 64 accumulator 512 hidden 128 layers 4 (projection + gated + 2 ReGLU) parameters with mix 1,673,111 multiply-adds after folding 211,328

One evaluation, with the planned heads

  1. Accumulator, 512: as in the NNUE, acc = ReLU(Σ_k W_k·t_k + b_mix + F·t_f + Σ_j R[f_j]).
  2. Projection, 128: h₀ = W₁·acc + b₁, no ReLU.
  3. Gated layer: h = h₀ + α₁·W_down·(ReLU(h₀) ⊙ (W_up·h₀ + b)), W_down without bias. Without reglu it is h = ReLU(h₀ + α₁·(W·ReLU(h₀) + b)) and the later layers residual.
  4. ReGLU blocks: h ← h + α_l·W_d·(ReLU(W_g·h + b) ⊙ (W_u·h + b)) for l = 2, 3, width 128, W_d without bias. Each α is 1 unless rezero makes it a learned scalar starting at 0.
  5. Value (planned): [v, z] = V·h + b, g = σ(z), wdl = (1 − g)·v + g·S·acc.
  6. Policy (planned): [γ, γ′] = σ(U·h + b), p[b·9 + s] = (P·h + b_P)[b·9 + s] + γ_b·L[c_b][s] + γ′_s·T[c_s].
